# **App Name**: CRANE Consults

## Core Features:

- Resource Library: Provide a library of guides on research methodologies.
- AI Prompt Library: A collection of AI prompts to improve research productivity; the LLM does not reason about its usage in this tool.
- Gemini Gems Integration: Curated links to pre-configured Gemini AI research tools.
- Newsletter Signup: Collect user emails for a research newsletter using Firestore.
- Firebase Integration: Use Firestore to manage guides, prompts, and newsletter subscribers.

## Style Guidelines:

- Primary color: Gold (#A1783D) for warmth and expertise.
- Secondary color: Blue (#678DBB) for trust and professionalism.
- Background color: Off-White (#FAFAFA) for a clean and modern look.
- Body and headline font: 'PT Sans', a humanist sans-serif. Note: currently only Google Fonts are supported.
- Use golden crane logo with blue wings as a recognizable brand icon.
- Minimal and clean design with generous padding to enhance readability.
- Smooth and purposeful animations (ease-in-out, 300-500ms) for a professional feel.
